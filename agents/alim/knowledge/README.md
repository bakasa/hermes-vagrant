# Alim Agent — Knowledge Base

This directory stores the growing knowledge base for the Alim Agent.

## Structure

- `_index.json` — Master index of all entries
- `_classroom/` — Google Classroom synced data (auto-generated)
- `_glossary/` — Islamic terminology definitions
- `_progress/` — Student progress tracking
- `aqeedah/` — Islamic creed and theology notes
- `fiqh/` — Jurisprudence notes
- `usul-al-fiqh/` — Principles of jurisprudence
- `hadith-sciences/` — Hadith methodology
- `seerah/` — Prophetic biography
- `tafsir/` — Qur'anic exegesis
- `arabic/` — Arabic language notes
- `ulum-al-quran/` — Qur'anic sciences
- `general/` — General Islamic studies notes

## Usage

The agent populates this directory automatically through:
1. Google Classroom sync (assignments, materials, announcements)
2. Study sessions (notes, summaries, key points)
3. Q&A exchanges (answered questions stored for review)
4. Progress tracking (study activity, test scores, milestones)

All data in this directory can be reviewed, edited, and expanded by the student.
Do NOT edit files in `_classroom/` manually — they are auto-generated.
